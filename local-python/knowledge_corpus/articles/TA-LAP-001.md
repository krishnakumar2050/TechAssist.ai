# Laptop fails POST after a RAM upgrade

ID: TA-LAP-001 | Platform: Dell laptops | Category: hardware / memory

Symptom: Power is present but startup fails after memory replacement
Possible causes (not confirmed): Incompatible or incorrectly installed RAM
Resolution:
1. Record model and diagnostic lights
2. Check upgrade compatibility in the exact service manual
3. Have a qualified person check installation with power isolated and ESD precautions
Verify: Manufacturer logo and normal startup return
Escalate: Soldered memory or continued failure requires service
Source: https://www.dell.com/support/kbdoc/en-us/000141584/how-to-troubleshoot-a-no-post-issue-on-a-dell-notebook-pc
