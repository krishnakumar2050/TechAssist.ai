# Laptop fan runs loudly all the time

ID: TA-LAP-004 | Platform: Dell laptops with Windows | Category: hardware / cooling

Symptom: Continuous high fan speed
Possible causes (not confirmed): High CPU load or restricted airflow
Resolution:
1. Check Task Manager for sustained CPU load
2. Close unnecessary workload
3. Check vents and follow model cleaning instructions
Verify: Fan settles after workload drops
Escalate: Abnormal fan behavior at idle requires support
Source: https://www.dell.com/support/kbdoc/en-us/000130867/how-to-troubleshoot-a-overheating-shutdown-or-thermal-issue-on-a-dell-pc
