# Windows cannot connect to Wi-Fi

ID: TA-LAP-006 | Platform: Windows 11 | Category: software / networking

Symptom: Wireless connection fails
Possible causes (not confirmed): Wireless disabled or network configuration issue
Resolution:
1. Check Wi-Fi and airplane mode
2. Check the selected network
3. Run the Windows network troubleshooter
Verify: Reconnect and open a known website
Escalate: Escalate with adapter model and exact error
Source: https://support.microsoft.com/en-us/windows/experience/connectivity-networking/fix-wi-fi-connection-issues-in-windows
