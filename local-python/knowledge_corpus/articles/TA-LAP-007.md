# Windows shows Wi-Fi connected but no internet

ID: TA-LAP-007 | Platform: Windows 11 | Category: software / networking

Symptom: Connected wireless icon but internet unavailable
Possible causes (not confirmed): Router or internet service or network settings
Resolution:
1. Check connection status
2. Compare another device on the same network
3. Run the network troubleshooter
Verify: Internet access returns on affected laptop
Escalate: If multiple devices fail contact network administrator or ISP
Source: https://support.microsoft.com/en-us/windows/experience/connectivity-networking/fix-wi-fi-connection-issues-in-windows
