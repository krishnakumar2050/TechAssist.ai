# Windows camera works in one app only

ID: TA-LAP-008 | Platform: Windows 11 | Category: software / camera_permissions

Symptom: Camera preview works but meeting app fails
Possible causes (not confirmed): App permissions or app settings
Resolution:
1. Check Windows camera access for the affected app
2. Check desktop app permission where applicable
3. Select the camera in the meeting app
Verify: Preview works inside the affected app
Escalate: Managed permission policy requires IT help
Source: https://support.microsoft.com/en-us/windows/hardware/camera/camera-doesn-t-work-in-windows
