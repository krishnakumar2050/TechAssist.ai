# Windows stop error after a new peripheral

ID: TA-LAP-010 | Platform: Windows 11 | Category: software / crashes

Symptom: Stop screen after hardware addition
Possible causes (not confirmed): New hardware or associated driver
Resolution:
1. Record stop code
2. Shut down and disconnect the new external device
3. Restart
4. Check Device Manager and approved updates
Verify: Normal use no longer reproduces the crash
Escalate: Repeated failures need IT diagnosis
Source: https://support.microsoft.com/en-us/windows/experience/performance-optimization/troubleshooting-windows-unexpected-restarts-and-stop-code-errors
