# Windows repeatedly crashes during startup

ID: TA-LAP-011 | Platform: Windows 11 | Category: software / crashes

Symptom: Repeated stop codes or restart loop
Possible causes (not confirmed): Driver or system issue
Resolution:
1. Record stop code and recent changes
2. Use supported recovery startup settings for Safe Mode if needed
3. Check Device Manager and free space
Verify: Startup and normal workload remain stable
Escalate: Unresolved crashes require support and diagnostic logs
Source: https://support.microsoft.com/en-us/windows/experience/performance-optimization/troubleshooting-windows-unexpected-restarts-and-stop-code-errors
