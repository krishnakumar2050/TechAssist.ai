# Windows unstable after a recent change

ID: TA-LAP-013 | Platform: Windows 11 | Category: software / os_recovery

Symptom: New freezes or crashes
Possible causes (not confirmed): Recent software or system change
Resolution:
1. Identify change
2. Back up important files
3. Compare applicable recovery options and try least disruptive first
Verify: Previous failing workload succeeds
Escalate: Reset and reinstall need explicit data-loss review
Source: https://support.microsoft.com/en-us/windows/experience/backup-recovery/recovery-options-in-windows

Reviewed: 2026-11-03. Original editorial summary; not lab tested.
