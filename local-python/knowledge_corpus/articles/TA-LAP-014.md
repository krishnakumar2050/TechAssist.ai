# Bluetooth device will not pair

ID: TA-LAP-014 | Platform: Windows 11 | Category: software / bluetooth

Symptom: Pairing fails or Bluetooth unavailable
Possible causes (not confirmed): Connection settings or adapter issue
Resolution:
1. Run Bluetooth troubleshooter in Get Help
2. Follow the matching symptom guidance
3. Record adapter and peripheral model
Verify: Device pairs and performs its intended function
Escalate: Persistent missing adapter requires support
Source: https://support.microsoft.com/en-us/windows/hardware/bluetooth/fix-bluetooth-problems-in-windows
