# Bluetooth headphones connected without sound

ID: TA-LAP-015 | Platform: Windows 11 | Category: software / bluetooth_audio

Symptom: Headphones paired but silent
Possible causes (not confirmed): Wrong output selection or driver issue
Resolution:
1. Select headphones as sound output
2. Check volume
3. Run Bluetooth troubleshooter
4. Remove and pair again if needed
Verify: Test audio plays in headphones
Escalate: Persistent failure requires adapter and headset compatibility review
Source: https://support.microsoft.com/en-us/windows/hardware/bluetooth/fix-bluetooth-connected-but-no-sound-issue-on-windows

Reviewed: 2026-11-03. Original editorial summary; not lab tested.
