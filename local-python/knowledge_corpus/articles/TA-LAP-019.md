# Windows update cannot proceed because storage is full

ID: TA-LAP-019 | Platform: Windows 11 | Category: software / storage

Symptom: Update requests more free storage
Possible causes (not confirmed): Insufficient disk space
Resolution:
1. Review Storage settings
2. Remove only reviewed unnecessary files or move backed-up personal data
3. Follow Windows Update space guidance
Verify: Update has sufficient space and completes
Escalate: Unknown files or insufficient capacity require support
Source: https://support.microsoft.com/en-gb/windows/deployment/updates-lifecycle/free-up-space-for-windows-updates

Reviewed: 2026-11-03. Original editorial summary; not lab tested.
