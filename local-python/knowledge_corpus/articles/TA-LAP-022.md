# External keyboard or mouse fails in Windows

ID: TA-LAP-022 | Platform: Windows 11; external devices | Category: hardware / input_devices

Symptom: Peripheral does not respond
Possible causes (not confirmed): Device connection or driver issue
Resolution:
1. Check connection
2. Test device on another compatible PC
3. Check Windows Update and device driver
Verify: Input works consistently
Escalate: Device failing on multiple PCs may need replacement
Source: https://support.microsoft.com/en-us/windows/hardware/input-devices/mouse-and-keyboard-problems-in-windows

Reviewed: 2026-11-03. Original editorial summary; not lab tested.
