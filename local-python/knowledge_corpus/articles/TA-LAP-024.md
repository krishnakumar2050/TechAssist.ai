# Mac shows flashing question mark at startup

ID: TA-LAP-024 | Platform: macOS | Category: software / mac_startup

Symptom: Question mark during startup
Possible causes (not confirmed): Startup disk unavailable or not selected
Resolution:
1. Follow model-specific startup options
2. If a disk is available select it
3. Set the correct Startup Disk after successful boot
Verify: Mac starts from the intended disk
Escalate: Missing or unrepairable disk requires service
Source: https://support.apple.com/guide/mac-help/if-your-mac-stops-or-delays-while-starting-up-mchlp2580/mac
