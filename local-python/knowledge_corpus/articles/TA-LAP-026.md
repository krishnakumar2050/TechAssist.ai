# Mac storage has filesystem errors

ID: TA-LAP-026 | Platform: macOS | Category: software / filesystem

Symptom: Disk Utility reports storage errors
Possible causes (not confirmed): Filesystem or directory inconsistency
Resolution:
1. Back up accessible files
2. Follow Apple guidance to run Disk Utility First Aid
3. Use macOS Recovery when required for startup disk repair
Verify: First Aid succeeds and files are accessible
Escalate: Failed repair requires support before erase or replacement
Source: https://support.apple.com/en-lamr/102611

Reviewed: 2026-11-03. Original editorial summary; not lab tested.
