# Ubuntu laptop has Wi-Fi turned off

ID: TA-LAP-027 | Platform: Ubuntu desktop with NetworkManager | Category: software / networking

Symptom: No wireless connection
Possible causes (not confirmed): Airplane mode or wireless switch disabled
Resolution:
1. Check physical wireless switch if present
2. Enable Wi-Fi and disable airplane mode
3. Inspect nmcli device output
Verify: Wireless adapter shows connected after joining network
Escalate: Missing adapter needs hardware and driver diagnosis
Source: https://help.ubuntu.com/stable/ubuntu-help/net-wireless-troubleshooting-initial-check.html.te
