# Windows external monitor is not detected

ID: TA-LAP-029 | Platform: Windows 11 | Category: hardware / display

Symptom: External display absent
Possible causes (not confirmed): Cable or adapter or display mode issue
Resolution:
1. Select Extend with Windows plus P
2. Check cable
3. Test another cable and monitor on another computer
4. Bypass dock where possible
Verify: External screen appears and remains stable
Escalate: Persistent fault requires port and graphics review
Source: https://support.microsoft.com/en-gb/windows/hardware/display-graphics/troubleshoot-external-monitor-connections-in-windows

Reviewed: 2026-11-03. Original editorial summary; not lab tested.
