# External display stopped after a driver update

ID: TA-LAP-030 | Platform: Windows 11 | Category: software / graphics_driver

Symptom: Previously working display fails after update
Possible causes (not confirmed): Possible display driver regression
Resolution:
1. Restart
2. Try Windows plus Ctrl plus Shift plus B
3. Use Device Manager driver rollback if available and appropriate
Verify: External display returns
Escalate: Unavailable rollback or ongoing failure requires support
Source: https://support.microsoft.com/en-gb/windows/hardware/display-graphics/troubleshoot-external-monitor-connections-in-windows

Reviewed: 2026-11-03. Original editorial summary; not lab tested.
