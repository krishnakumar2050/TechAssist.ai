# Windows speakers or headphones have no sound

ID: TA-LAP-031 | Platform: Windows 11 | Category: software / audio

Symptom: Silent output
Possible causes (not confirmed): Wrong output or mute or loose connection
Resolution:
1. Select intended output
2. Check system and application volume
3. Check cables and headphones
4. Run audio troubleshooter
Verify: Test sound plays through intended output
Escalate: Persistent failure requires driver or hardware diagnosis
Source: https://support.microsoft.com/en-us/windows/hardware/audio/fix-sound-or-audio-problems-in-windows

Reviewed: 2026-11-03. Original editorial summary; not lab tested.
