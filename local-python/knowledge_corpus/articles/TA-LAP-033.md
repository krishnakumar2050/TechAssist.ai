# Windows asks for a BitLocker recovery key

ID: TA-LAP-033 | Platform: Windows 11 | Category: software / disk_encryption

Symptom: Encrypted drive locked at startup
Possible causes (not confirmed): Security or hardware change can trigger recovery
Resolution:
1. Record recovery key ID
2. Locate matching key in Microsoft account or work or school account or saved backup
3. Enter it locally
4. Contact organization IT if managed
Verify: Drive unlocks and startup completes
Escalate: A lost key cannot be recreated by Microsoft; reset removes files
Source: https://support.microsoft.com/en-us/windows/security/encryption/find-your-bitlocker-recovery-key

Reviewed: 2026-11-03. Original editorial summary; not lab tested.
